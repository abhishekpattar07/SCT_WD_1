# 🚀 TECHSPARK 2.0

### Ignite Ideas. Build the Future.

A modern and responsive **Tech Fest Landing Page** created for **A.S. Patil College of Commerce, Vijayapura, Karnataka, India**.

This project was developed as **Task 1** of my **Web Development Internship at SkillCraft Technology**.

---

## 📌 About the Project

**TechSpark 2.0** is a modern technology fest landing page designed to showcase a college-level technical event.

The website provides information about:

* 🎯 Tech Fest and event details
* 💡 Technical events and activities
* 📅 Event schedule
* 🏆 Prize details
* 🤝 Sponsors
* 📞 Contact information

The project focuses on creating a modern, responsive, interactive, and user-friendly web experience.

---

## ✨ Features

* Responsive design
* Modern and attractive user interface
* Navigation bar
* Responsive mobile hamburger menu
* Hero section with call-to-action buttons
* Countdown timer
* About section with event statistics
* Technical event cards
* Event schedule
* Prize section
* Sponsors section
* Registration call-to-action
* Contact form
* JavaScript form validation
* Smooth scrolling
* Active navigation links
* Scroll-to-top functionality
* CSS animations and hover effects

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open the `index.html` file.
4. Run the project using:

   * Live Server extension, or
   * Open `index.html` directly in a web browser.
